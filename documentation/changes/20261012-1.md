# Report subscriptions missing required env keys

- New read-only `php artisan app:report-missing-env [keys…] [--type=ID…] [--json]` (`ReportMissingEnvCommand`). For every subscription whose type has a required-env template it lists template keys that have no `EnvVariables` row (`no_row`), an empty row where the template has a value or needs a manual one (`empty`), or are absent from the env last pulled from Forge (`not_on_site`). Exits non-zero when anything is listed. No Forge calls, nothing is written.
- Example: `php artisan app:report-missing-env COOKIE_DOMAIN` finds tenants whose shared SSO cookie stays host-only, which makes `/go` refuse with `no_cookie`.
- Tests: `tests/Feature/ReportMissingEnvCommandTest.php`.
