# Token-user resolves the shared LMS hub per customer

- `POST /api/token-user` now looks up the subscription at `app_url` for the token user's own customer (falling back to `LmsTenantResolver` URL normalisation), instead of the first subscription at that URL. Many customers share the LMS hub URL, so SSO previously failed for all but one of them.
- Tests added to `tests/Feature/SsoTokenUserTest.php`.
