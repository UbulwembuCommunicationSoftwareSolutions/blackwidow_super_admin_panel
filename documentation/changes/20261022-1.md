# 2026-10-22 — Staff users are the LMS admin users

- New `UserObserver`: creating a staff `User`, or changing their name, email or password, queues `PushStaffUserToLmsJob` to the shared LMS (`POST {LMS_HUB_URL}/admin-api/v1/sync/staff`); deleting one archives the LMS admin user (`/staff/archive`).
- `App\Services\Lms\LmsStaffPusher` sends the bcrypt password hash, never cleartext. Only active when `services.lms.hub_url`, `services.lms.sync_token` and `user_sync.enabled` are set.
- `php artisan lms:push-staff [--dry-run]` pushes every staff user (initial seed or repair).
- Needs the matching LMS staff sync endpoints.
- Tests: `tests/Feature/LmsStaffSyncTest.php`.
