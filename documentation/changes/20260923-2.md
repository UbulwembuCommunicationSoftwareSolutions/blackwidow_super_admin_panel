# LMS hub without a customer subscription

- Shared LMS is `LMS_HUB_URL` plus `LMS_SYNC_TOKEN`. Customer, user, branding, and user-field pushes no longer need a type-12 subscription.
- A type-12 subscription URL remains only when `LMS_HUB_URL` is empty.
- Documented in `docs/TENANT_SYNC_INTEGRATION.md`.
