# LMS handoff keeps the course path

- `/go` to an LMS URL with a path or query (for example `/courses/5` from the CMS course menu) now appends it to the LMS consume link as `next`, so the member lands on that course instead of the dashboard. The bare LMS host is unchanged. The LMS decides whether `next` is safe to follow.
- `CrossAppHandoffService::withNextPath()`.
- Tests: `tests/Feature/CrossAppHandoffTest.php`.
